# Helsing Chrome Theme

This folder contains the generated Chrome browser theme manifest.

## Generate

From the repo root:

```bash
.venv/bin/python generator/generate.py
```

## Load Locally

1. Open `chrome://extensions`
2. Enable `Developer mode`
3. Choose `Load unpacked`
4. Select this `themes/chrome` folder
